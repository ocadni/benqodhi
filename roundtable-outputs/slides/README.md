# Recap slides

Short presentation decks for the Day 2 recap (11:15) and plenary consolidation
(11:35). One deck per table is enough — keep it to a handful of slides, since each
rapporteur has only a few minutes.

- Add your table's deck here (e.g. `table-1-slides.md`, `table-2-slides.md`, ...).
- Any format the note taker is comfortable with is fine: plain Markdown, a
  [Quarto reveal.js](https://quarto.org/docs/presentations/revealjs/) `.qmd`, or an
  exported PDF. Keeping the source here means the decks stay in the repository for
  the closing sessions.
- See [`table-4-slides-example.qmd`](table-4-slides-example.qmd) for an example.

## Suggested slide outline (matches the recap guidance)

1. Table name and main conclusion
2. Main candidate problem / infrastructure need / policy or instrument need
3. Why it matters + most important missing piece
4. Next benchmark-building action
5. Answer to the transversal governance question
